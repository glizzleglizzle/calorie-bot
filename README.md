# 🥗 AI Calorie Tracker Telegram Bot (Аналог YAZIO)

Telegram-бот для автоматического подсчета калорий и БЖУ по фотографиям еды и текстовым описаниям с использованием Google Gemini Vision AI.

## Возможности:
- 📸 **Анализ фото еды:** распознавание блюда, веса порции и расчет КБЖУ (калории, белки, жиры, углеводы).
- 💬 **Текстовый дневник:** можно написать состав приема пищи текстом.
- 📊 **Суточная сводка:** красивый прогресс-бар нормы калорий и баланс БЖУ за день.
- 🎯 **Установка целей:** настройка индивидуальной суточной нормы калорий.
- ☁️ **Работает в облаке 24/7 бесплатно** (поддерживает Render.com, Koyeb, Railway).

## Быстрый запуск на Render.com (Бесплатно 24/7):
1. Загрузите файлы репозитория на GitHub.
2. Войдите на [render.com](https://render.com) через GitHub.
3. Нажмите **New +** -> **Web Service**.
4. Подключите ваш репозиторий.
5. Настройки:
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** `Free`
6. Нажмите **Create Web Service**.
